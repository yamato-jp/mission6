『将来ロードマップ作成サービス』企画書

「自己投資の収支を自動でシミュレーション・可視化するWebツール」


【テーマ/背景】
　自己投資をしても「いつ回収できるのか」「何年後にいくら稼いでいるか」が
　具体的にイメージしにくいという課題がある。
　自己投資額・収入開始時期・月収・シミュレーション期間を入力するだけで、
　「1年後・2年後・3年後にいくら稼いでいるか」を自動計算し、
　収支の推移をグラフで可視化することを目的とする。

【ターゲット層】
　① 自己投資中の大学生
　スキルアップや資格取得・インターン参加など
　自己投資を通じて市場価値を高めたい大学生。
　投資対効果を数字で確認したい人向け。

② 転職を目指す社会人
　プログラミングスクールや資格取得などに
　費用をかけて転職活動中の人。
　「いつ元が取れるか」を明確にしたい人向け。

③ フリーランス・副業志望者
　自分のスキルをサービスとして企業や個人に
　販売することを目指している人。
　収入シミュレーションで計画を立てたい人向け。

【構成】
・	入力フォーム（自己投資額・収入開始時期・月収・シミュレーション期間）
・	収支シミュレーション自動計算（月ごとの累計収入・収支を算出）
・	投資回収点の表示（何ヶ月後にプラスになるか）
・	「1年後・2年後・3年後」の累計収入と純利益の表示
・	グラフによる収支推移の表示（Chart.js 使用）
・	CSVダウンロード機能
・	個人情報不要／ページを閉じたらデータ自動削除

【使い方】
1.	入力画面で自己投資額・収入開始時期・月収・期間を入力する
2.	「ロードマップを作成する」ボタンで送信
3.	結果画面で1年後・2年後・3年後の収支とグラフを確認する
4.	必要に応じてCSVダウンロードで手元に保存する
